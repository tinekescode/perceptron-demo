Handwritten digits

A 784 → 64 → 10 network learns to read handwritten digits (MNIST) with backpropagation.

Connecting…

Every image is 28 × 28 = 784 pixels, so the network has 784 inputs. Each hidden neuron is a perceptron over all 784 pixels; the 10 outputs give a probability per digit. Draw a digit before training: the network guesses. Then press Train and watch the guesses, the accuracy and the hidden neurons change.
