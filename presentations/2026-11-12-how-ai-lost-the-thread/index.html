Classic network
150,528 pixel values × 1,000 neurons

ConvNet
64 filters × (3 × 3 pixels × 3 colours)

fewer weights

Transformers — The Problem
Perceptrons & Simple Nets
1958 →
Good at: simple patterns in a fixed set of inputs.
Struggles with: order and context. No memory of what came before, and not enough depth.
Transformers — The Problem
Convolutional Nets
1989 →
Good at: local patterns — a few neighbouring words.
Struggles with: words that belong together but are far apart.
Transformers — The Problem
RNNs & LSTMs
1990s →
Good at: reading in order, carrying a memory along.
Struggles with: long texts, because the memory fades. And speed: word 100 waits for word 99.
